## Instructions

This exercise starts with a `NonEmptyArray` that is currently `unknown`:

```tsx
type`NonEmptyArray` = unknown
```

### Challenge

Your challenge is to update ``NonEmptyArray` so that it accepts an argument and turns it into an array with a length of at least one.

As seen in the tests, there should be an error if an empty array is passed in.

Hint: The TypeScript docs on the <a href="https://www.typescriptlang.org/docs/handbook/2/objects.html#tuple-types" target="_blank" rel="noopener">Tuple type</a> may come in handy.

## Solutions

<details>
<summary>Click For Solution</summary>

The first step to solving this challenge is to update ``NonEmptyArray`to accept`T`. Since we are working with arrays, we can replace` unknown`with an array of`T`:

```tsx
type NonEmptyArray<T> = Array<T>
```

This will still accept arrays with a length of zero, so there's more work to be done.

In order to avoid empty arrays, we need to specify a tuple.

For example, we could update `NonEmptyArray` like this:

```tsx
type NonEmptyArray<T> = [T, T, T]
```

However, the problem now is that we can't have an array with more than 3 items.

The solution to this challenge is to use the rest parameter `...` along with `Array<T>`:

```tsx
type NonEmptyArray<T> = [T, ...Array<T>]
```

The first `T` enforces that there is at least one item in the array, while supporting however many more items may be there thanks to the rest parameter.

This technique is used in the Zod library, and is useful in a variety of situations in application code as well.
